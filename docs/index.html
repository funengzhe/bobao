常见问题

要花钱吗？

Bobao 免费。用电脑自带的声音完全不花钱。想用这里的好听声音，要用你自己的如云账号生成一次你的全部说法，一般一两个积分；生成前智能体会先告诉你价格，你同意才生成。生成好存在你的电脑上，以后每次播报都不再花钱，断网也能念。

我的消息会被上传吗？

不会。消息只在你自己的电脑上处理。只有生成声音的那一次，要念的句子（不是你的消息）会发给如云。

能读哪些消息？

电脑上任何 App 弹出的通知：飞书、企业微信、钉钉、微信、日历、邮件……；飞书群里机器人发的卡片；你自己系统发来的 Webhook；还有你设定的定时提醒。

公司电脑、公司的飞书也能用吗？

能。读电脑弹窗不需要公司开任何权限，也不碰你的账号。个人微信、钉钉也只读弹窗，不做任何接口或外挂，没有封号风险。

还要另外装如云吗？

不用。Bobao 自己会连如云，换声音时浏览器里登录如云、点一下「授权」就行。

能用我自己的声音吗？

能。声音可以个性化定制：在如云里克隆你自己或家人的声音，或者描述一个声音让如云设计，也可以挑如云里这 22 个以外的音色。做好后告诉智能体「用我在如云做的那个声音」，它会找到并帮你生成。

Windows 能用吗？

目前只支持 macOS。
