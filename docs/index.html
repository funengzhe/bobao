Bobao 定制播报

把你在意的消息，用你喜欢的声音、你想听的话念出来。上班、做生意、写代码、做直播、过日子，都可以。

能做什么

每一句都可以换成你自己的说法。示范声音：。

谁来念

挑一个你喜欢的声音。接入如云后，用它把你的播报内容生成一遍就能用；不接如云，用电脑自带的声音。

装好的第一声

安装成功时会听到这一句。

怎么开始

把这个链接发给你的智能体（Claude Code、Codex、Cursor 等），说一句：

帮我装上 Bobao：https://github.com/funengzhe/bobao

它会问你想听哪些提醒、消息从哪来、怎么称呼你，然后装好。想换声音、改说法，之后也直接跟它说。目前只支持 macOS。

试听音频仅供试听，不得提取或商用（条款）。代码：github.com/funengzhe/bobao
