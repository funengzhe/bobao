# 试听音频的使用条款

本目录里的音频是用[如云](https://www.rooyun.com)的音色生成的示例，**只用于试听，方便你挑选风格和音色**。它们不受仓库根目录 MIT + Commons Clause 许可证的约束，适用下面这些条款：

- 可以：在本仓库、GitHub Pages 试听页面，以及原样克隆的本仓库里收听这些音频。
- 不可以：把这些音频单独提取出来使用、再分发，或者用在任何商业用途里，包括放进你的产品、视频、广告和铃声。
- 想在自己的播报里用这些声音：运行 `bobao voice record`，用你自己的如云账号生成属于你的录音，并按如云的用户协议使用。
