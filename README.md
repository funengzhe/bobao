**Bobao 定制播报**：老板 @你、钱到账、构建失败、外卖到了、妈妈来消息……不用一直盯着屏幕，有人替你听着，用你想听的话、你喜欢的声音告诉你。

| 谁 | 会听到 |
|---|---|
| 💼 上班的人 | "注意注意，老板刚刚在群里点你名了，好像挺着急的，快去看看吧。" |
| 🛍️ 商家、店主 | "大单来啦，刚刚到账 5000 元，老板威武，今晚加个鸡腿。" |
| 💻 开发、运维 | "构建失败了，好像是测试没过，快去看看是哪里出错了。" |
| 🎥 主播、创作者 | "感谢大哥送的火箭，直播间一下子沸腾啦，快跟大哥说声谢谢。" |
| 🏠 每个人的生活 | "外卖到楼下啦，忙了一上午，先放下手里的事，快去吃饭吧。" |

每一句都能换成你自己的说法。**[点这里听听这些话念出来是什么样 →](https://funengzhe.github.io/bobao/)**

## 30 秒装好

把这句话发给你的智能体（Claude Code、Codex、Cursor 等）：

```
帮我装上 Bobao：https://github.com/funengzhe/bobao
```

它会照着 [AGENTS.md](AGENTS.md) 一步步做，问你三个问题：想听哪些提醒、消息从哪来、喜欢什么样的声音。装好时你会听到一声风铃和一句安装提示，然后它会放几个适合你的声音给你听，帮你换上。之后想换声音、改说法、加提醒，也直接跟它说，比如：

- "老板在群里 @我的时候，说'老板找你啦'"
- "工作日下午五点半提醒我写日报"
- "到账超过一千块，加一句'大单来啦'"
- "我想换成安然的声音"

支持 macOS；Windows 是测试版：飞书、定时提醒、智能体等都能用，微信和其他 App 的弹窗还读不了。想自己动手装，见[使用说明](GUIDE.md#自己装)。

## 能读哪些消息

- **电脑上的弹窗**：飞书、企业微信、钉钉、微信、日历、邮件……任何 App 的通知。公司电脑也能用，不用开权限、不碰账号。
- **飞书群里的机器人通知**：建一个「飞书播报」应用，几秒内推送。
- **你自己的系统**：发一个 Webhook 过来就行。
- **定时提醒**：下班、写日报、早点睡、明早的高铁。

个人微信、钉钉只读弹窗，不做接口或外挂，没有封号风险。

## 声音

- **默认用电脑自带的声音**，免费，装好就能念。
- **想要好听的，在[试听页](https://funengzhe.github.io/bobao/#voices)挑一个**：新闻主播、御姐、温柔男友、机器人、小朋友……22 个声音。用你自己的[RooYun（如云）](https://www.rooyun.com/?ref=9K3XD33J&ch=github-bobao)账号把你的说法生成一次，一般一两个积分，生成前会先告诉你价格；之后一直免费播，断网也能念。不需要另外安装 RooYun 的工具。
- **声音可以个性化定制**：这 22 个只是推荐，[RooYun（如云）](https://www.rooyun.com/?ref=9K3XD33J&ch=github-bobao)里有更多音色；也可以克隆你自己、家人的声音，或者描述一个声音让 RooYun 帮你设计。做好后告诉智能体「用我在 RooYun 做的那个声音」就行。

## 好玩的

- **智能体干完活叫你**：Claude Code、Codex、Cursor 等跑完一个长任务，电脑说"活儿干完啦，快回来看看"。
- **项目涨星有人报喜**：你的 GitHub 项目有新的 star、fork、Issue，马上念给你听。
- **做一句能发出去的**：任意一句话、任意一个声音，生成 mp3 和视频，发给朋友、发朋友圈。
- **让朋友来喊话**：聚会、开店的时候，朋友扫个码、打几个字，你的电脑就替他大声念出来。

跟你的智能体说"你干完活叫我一声""用安然的声音做一句'欢迎来我家玩'""开一下喊话"就行。

## 隐私

消息只在你自己的电脑上处理，不上传。只有生成声音的那一次，要念的句子（不是你的消息）会发给 RooYun（如云）。喊话页只在你的 Wi-Fi 里能打开。
